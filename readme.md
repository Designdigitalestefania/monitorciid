# MONITOR CIID · Demo navegable

Piloto con datos ficticios. Uso exclusivo de demostración.

## Uso local
Abre `index.html` en cualquier navegador moderno.

## Publicar
Sube esta carpeta a Netlify Drop, Vercel, Cloudflare Pages o GitHub Pages.

## QR
    qrencode -o assets/qr-demo.png -s 10 -m 2 "TU_URL"

## Servir localmente
    python -m http.server 8080

## Assets
- `card-demo1.svg` / `card-demo1.png` → card de portada de la Demo 1
- `card-demo2.svg` / `card-demo2.png` → card de portada de la Demo 2
- `audio-demo.wav` → audio ficticio en lengua originaria
- `logo-ciid.svg` → logo MONITOR CIID
- `logo-monitor-noticias.svg` → logo de la marca periodística
